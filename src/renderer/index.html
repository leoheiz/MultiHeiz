Modelo local: conecte ao Ollama (http://127.0.0.1:11434) ou LM Studio (http://127.0.0.1:1234/v1) se já tiver instalado. Baixar pelo MultiHeiz ainda está em breve — por enquanto use o Ollama:

  • Qwen2.5 1.5B Instruct (~1 GB, recomendado) — ollama pull qwen2.5:1.5b-instruct
  • Gemma 3 1B (~800 MB, leve) — ollama pull gemma3:1b
  • Gemma 3 4B (~2,5 GB; pede 6–8 GB de RAM livres) — ollama pull gemma3:4b

Aviso: o download consome espaço em disco e banda. O MultiHeiz não embute runtime nesta etapa.

      Extensões Experimental (em testes)

      Recurso em testes: pode não funcionar em todos os sites. Extensões de bloqueio aplicam só as regras de rede (DNR via shim do MultiHeiz); esconder elementos na página (cosmético) é limitado. Em http://127.0.0.1 (loopback) algumas extensões podem falhar — sites https normais costumam OK.

      Parte do recurso Experimental (em testes). Liga shims de API do service worker (webNavigation, DNR, etc.) para extensões MV3 com background.service_worker. Reinicie as janelas afetadas após alterar.

      Nas páginas de detalhe da loja, use Instalar no MultiHeiz na barra acima do painel.

      Instalar de arquivo ou pasta (avançado)

      Licença: camada própria (MIT). Não usamos electron-chrome-extensions (GPL-3) — ver Sobre e THIRD_PARTY_NOTICES.

      Modo legado: barra sempre visível (compacta, só ícones); a seta do topo alterna para expandida (com nomes) e de volta, sem esconder automaticamente.

      Escala por painel via zoom é possível; fator de escala do dispositivo por painel não é suportado pelo Electron — documentado em Desempenho.
